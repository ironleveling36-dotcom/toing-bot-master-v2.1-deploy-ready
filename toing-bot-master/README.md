# Toing Bot

Swiggy OTP login, device fingerprint rotation, and real-time cart & payment sync dashboard.

## Setup
1. Works out-of-the-box on Railway / Render / VPS even without MongoDB (automatically falls back to persistent local storage if `MONGODB_URI` is missing or invalid).
2. Run `npm install`.
3. Run `npm start` (or `node start.js`).
